# Sources

Every source `wss-uk-food-safety` captures, where it comes from and what it is allowed to be
used for. **Generated by `wss sources` — do not edit by hand.**

Each row links to the exact URL the capture fetches. To go from a number back to
its bytes: an observation carries `source_id` and `raw_ref`; the matching manifest
row under `manifest/<source_id>/` holds that `raw_ref` with the URL, the fetch
timestamp and a SHA-256 of exactly what came back.

## Each source in full

### `fsa.fhrs.ratings`

**Food Standards Agency** (first party) · monthly · active

One XML per local authority, 363 of them, ~900 bytes per establishment for roughly 550 MB a full capture. Each file carries its own Header with ExtractDate, ItemCount and ReturnCode, so the parser can check the count it parsed against the count the publisher declared rather than trusting its own loop. Smallest authority is River Tees with 3 establishments and largest is Birmingham with 10,221, so min_bytes can only be a floor for the smallest -- truncation of a large file is caught by max_shrink_pct, which the engine applies per endpoint against that endpoint's own previous capture.
